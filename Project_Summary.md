# Cyclistic Customer Behavior Analysis

## Project Summary

This project analyzes Cyclistic bike-share data to compare annual members and casual riders.

Using SQL and Tableau, I cleaned, analyzed, and visualized ride data to identify customer behavior patterns and provide business recommendations to support membership growth.

## Tools Used

- SQL (BigQuery)
- Tableau
- Google Sheets

## Key Objectives

- Compare member vs. casual riders
- Analyze average ride duration
- Identify ride trends by day of the week
- Examine rideable type preferences
- Provide data-driven business recommendations
